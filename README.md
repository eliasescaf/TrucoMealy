# Truco Mealy

Aplicacion web que modela el canto del Truco como una maquina de estados tipo Mealy. Permite ingresar cantos (Envido, Real Envido, Falta Envido, Truco, Retruco, Vale 4) y respuestas (Quiero / No Quiero), mostrando el estado actual, los puntos resultantes y el historial de cantos.

## Demo

https://trucomealy.vercel.app/

## Tecnologias

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS

## Ejecutar en local

```bash
pnpm install
pnpm dev
```

Abrir http://localhost:3000 en el navegador.

## Build

```bash
pnpm build
pnpm start
```
